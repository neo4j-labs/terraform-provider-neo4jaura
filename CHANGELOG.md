### Fixed

## 0.0.5-beta - 2026-05-11
### Added
* Add testAccPreCheck, testAccCheckInstanceDestroyed, TestAcc_instance_update, and TestAcc_instance_disappears to acceptance test suite; wire PreCheck and CheckDestroy into every resource.TestCase
* Add golangci-lint CI job (govet, errcheck, staticcheck) and .golangci.yml config; fix all pre-existing lint violations
* Provider now falls back to AURA_CLIENT_ID and AURA_CLIENT_SECRET environment variables when client_id and client_secret are not set in the HCL provider block, matching the existing AURA_BASE_URL pattern. The provider registry address in main.go is updated to registry.terraform.io/neo4j-labs/neo4jaura.
* Add TestAcc_instance_pause_resume acceptance test covering pause and resume lifecycle; fix mock server handleGetInstance to preserve status after explicit pause/resume transitions
* Add acceptance tests for snapshot datasource readSnapshotById and readMostRecentSnapshot branches, including isInstanceRecentlyCreated guard path
* Add TestAcc_snapshot_lifecycle acceptance test covering SnapshotResource Create (with WaitUntilSnapshotIsInState) and Delete (no-op) lifecycle
* Add unit tests for util.DiagnosticsError helpers and aura_responses CanBePaused, CanBeResumed, TimestampAsTime, CreatedAtAsTime
### Fixed
* InstanceResource.Read and SnapshotResource.Read now remove the resource from state on HTTP 404 (out-of-band deletion) instead of surfacing a hard error, enabling Terraform drift detection and planned recreation. A new ErrNotFound sentinel in the client layer allows errors.Is-based detection without string parsing.
* Fix "unexpected new value: .connection_url" error when pausing an instance — the Aura API returns an empty connection_url for paused instances; the provider now preserves the prior state value in both Update and Read instead of overwriting with empty string
* Add objectplanmodifier.RequiresReplace() to the source block on neo4jaura_instance so changing source after creation triggers replacement; add root id attribute to neo4jaura_projects data source set to "projects"
* InstanceResource.Update now refreshes all computed fields from the API after mutations instead of storing plan values; all AddError calls in resource and datasource code include the relevant resource ID; HasError() guards added after every resp.State.Set and resp.State.SetAttribute call

## 0.0.4-beta - 2026-05-11
### Fixed
* Replace hardcoded "completed" magic string in snapshot status comparisons with the domain.SnapshotStatusCompleted constant
* SnapshotDataSource.Read now returns early without calling State.Set when snapshot lookup returns nil, preventing zero values from being written to state
* Fix sort antisymmetry in readMostRecentSnapshot: a timestamp parse error now returns a diagnostic instead of silently producing an undefined sort order
* Fix redundant data.Status assignment in InstanceResource.Create so that state reflects the real API status instead of the planned value
* Add context.Context to WaitUntil so Terraform plan/apply cancellations are respected during polling wait intervals
* Mock server writeJSON now panics on JSON encoding failure instead of silently discarding the error, making test failures visible

## 0.0.3-beta - 2026-05-11
### Added
* Release workflow now generates the GitHub release body from changie changelog; prepare-release workflow automates versioning and tagging via changie
### Changed
* Acceptance tests moved to a dedicated workflow (acceptance.yml); build.yml now runs unit tests only, preventing real Aura instances being created on every pull request
### Fixed
* Conditionalize PATCH calls in InstanceResource.Update: name/memory PATCH is now sent only when those fields change, and secondaries_count PATCH is sent only when that field changes; if the secondaries_count PATCH fails after a name/memory PATCH already succeeded the error message clearly indicates which update succeeded
* Fix missing returns after error in InstanceResource.Create: execution no longer continues with invalid state when WaitUntilSnapshotIsInState or the first WaitUntilInstanceIsInState fails
